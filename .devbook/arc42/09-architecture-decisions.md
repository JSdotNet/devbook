Decisions taken and defensible. Records live in [`adr/`](adr/README.md) and are linked from
here rather than restated, the same way [chapter 11](11-risks-and-technical-debt.md) relates to

[chapter 11](11-risks-and-technical-debt.md) instead.

## The Decisions

```meta
related: [".devbook/arc42/adr/README.md"]
```

Numbered in the order they were argued rather than the order they were taken; `Taken` carries
the chronology. The [index](adr/README.md) says why, and what happens to a number when a
decision is superseded.

| [1. Marketplace Named jsdotnet](adr/1-marketplace-named-jsdotnet.md) | 2026-09-02 | The marketplace is `jsdotnet`, not `jsdotnet-copilot`, and is never renamed after release — the name is a per-machine primary key. Superseded by record 66 on the name; the warning stands. |
| [2. One Folder Per Plugin](adr/2-one-folder-per-plugin.md) | 2026-09-02 | Every plugin is self-contained under `plugins/<name>/` and either works alone or declares what it needs; dependency, bridge, and surface are the only three ways to couple. |
| [3. One Authored Copy Per Asset](adr/3-one-authored-copy-per-asset.md) | 2026-09-02 | An asset is written once and read by both hosts, and the cost of that is paid inside the authored file. |

| [6. Flat Devbook Folders Only](adr/6-flat-devbook-folders-only.md) | 2026-09-03 | Five root dot-folders or one `.devbook/` parent — a repository picks one layout and never mixes them. |
| [7. approved Is a Status Rung](adr/7-approved-is-a-status-rung.md) | 2026-09-03 | The approval gate's decision lives in the chapter as `status: approved`, with `approved-by` and `approved-at` beside it. |
| [8. | [9. The Point Set Is Closed](adr/9-the-point-set-is-closed.md) | 2026-09-03 | `delivery` declares eleven extension points and never adds one; a repository that needs a different shape writes a repo-native flow. |
| [10. One Config File, Two Kinds of Key](adr/10-one-config-file-two-kinds-of-key.md) | 2026-09-03 | The engine's four keys and every component's stamp share one committed file, because the same person decides both in one sitting. |
| [11. The Stack Config Lives in devbook](adr/11-the-stack-config-lives-in-devbook.md) | 2026-09-07 | The config is `.devbook/config.json`, not `.github/`, and reading that path is not a dependency on `devbook`. |

| [13. A Tracker Is a Binding, Not a Phase Name](adr/13-a-tracker-is-a-binding-not-a-phase-name.md) | 2026-09-03 | The closing phase is Work Item Update; no phase, stage list, or prose names GitHub. |
| [14. delivery Ships No Surface](adr/14-delivery-ships-no-surface.md) | 2026-09-03 | The engine resolves a surface from the live tool list and no-ops when none answers, so `delivery` alone gives no run timeline at all. |
| [15. Three Surfaces, One Contract](adr/15-three-surfaces-one-contract.md) | 2026-09-03 | Three plugins implement `delivery.surface.*@1` and none depends on the engine or on each other; the third is what makes the contract a contract. |
| [16. A Surface Declares Only the Contract's Tool Names](adr/16-a-surface-declares-only-the-contracts-tool-names.md) | 2026-09-03 | An extra tool is the first thing that makes one implementation not substitutable for another, so each surface exposes its operation names and nothing else. |
| [17. No Host Profile Plugins](adr/17-no-host-profile-plugins.md) | 2026-09-05 | `claude-desktop` and `copilot-app` are deleted; nothing here names one host's own file, path, or capability, and no plugin ships slot bindings. |
| [18. delivery-surface-canvas Ships the Canvas Only](adr/18-delivery-surface-canvas-ships-the-canvas-only.md) | 2026-09-05 | Its MCP half was a second implementation of a capability the dashboard already covered, so the canvas extension is the whole plugin. |
| [19. A Role Plugin Holds No Flow Control](adr/19-a-role-plugin-holds-no-flow-control.md) | 2026-09-04 | A specialist contributes expertise and artifacts; sequencing, gates, session spawning, and delegation belong to whatever consults it. |
| [20. Budgets Are Disclosure Triggers, Not Gates](adr/20-budgets-are-disclosure-triggers-not-gates.md) | 2026-09-05 | Past its budget an asset discloses, splits, or states a reason — and four kinds that are long by nature state theirs here, once. |
| [21. Four arc42 Chapters](adr/21-four-arc42-chapters.md) | 2026-09-05 | `.devbook/arc42` holds chapters 1, 5, 9, and 11 and the record folders, because a chapter is written when it has content, not to complete a set. |
| [22. Fan-Out Is Its Own Plugin](adr/22-fan-out-is-its-own-plugin.md) | 2026-09-03 | The sweep skills land in `fleet`, an L1 extension over `delivery`, so a flow splitting across sessions is impossible rather than discouraged. |
| [23. The Guide Names Every Plugin and Depends on None](adr/23-the-guide-names-every-plugin-and-depends-on-none.md) | 2026-09-07 | A skill that explains the stack must name every part of it, which no layer may do — so `devbook-config` is a plugin of its own with no dependencies. |
| [24. The Specialists Leave the Marketplace](adr/24-the-specialists-leave-the-marketplace.md) | 2026-09-07 | Seven role plugins are published elsewhere; what stays is the convention, the engine, the bridges, the surfaces, and the guide. |
| [25. Devbook Payload Named After Its Plugin](adr/25-devbook-payload-named-after-its-plugin.md) | 2026-09-05 | Every `knowledge-` name inside `devbook` becomes `devbook-`, down to the module constants. |
| [26. The Unattended Lane Is Its Own Plugin](adr/26-the-unattended-lane-is-its-own-plugin.md) | 2026-09-07 | Everything that runs with nobody watching is `delivery-schedule`, under one `schedule-*` prefix. |
| [27. One Rule, One Wrapper Per Host](adr/27-one-rule-one-wrapper-per-host.md) | 2026-09-07 | A rule is authored once in `.agents/rules/` and wrapped per host, replacing 154 lines of `CLAUDE.md` that loaded on every session. |
| [28. devbook Owns One Section of AGENTS.md](adr/28-devbook-owns-one-section-of-agentsmd.md) | 2026-09-07 | The install writes and reconciles one marked section, so what a repository's devbook holds is stated on disk instead of by a hook in every session. |
| [29. Automation Owns the _meta Refresh](adr/29-automation-owns-the-_meta-refresh.md) | 2026-09-07 | A schedule reconciles the derived indexes and opens a pull request; a session runs `--check` and never regenerates. |
| [30. The Handback Is the Commit Point](adr/30-the-handback-is-the-commit-point.md) | 2026-09-07 | A run commits where it hands back, so a reviewer can tell a handback from a mid-stage save. |
| [31. Every Run Opens With Update Base](adr/31-every-run-opens-with-update-base.md) | 2026-09-07 | The runner prepends the phase; no `flow-*/SKILL.md` names it. |
| [32. An MCP Server Is Bound Per Point](adr/32-an-mcp-server-is-bound-per-point.md) | 2026-09-07 | No flow names a server id or stops a run for MCP setup — servers bind to extension points the way plugins bind to roles. |

| [40. The Overlay May Add a Gate and Never Remove One](adr/40-the-overlay-may-add-a-gate-and-never-remove-one.md) | 2026-09-07 | `.devbook/config.local.json` says *on this machine*, and the asymmetry is what keeps a personal preference from weakening the team's run. |

| [42. A Tool Matcher Names Its Tools](adr/42-a-tool-matcher-names-its-tools.md) | 2026-09-07 | A `"*"` matcher is one process spawn per tool call in every session the plugin is enabled in; the guards inside the process are too late. |
| [43. Only a Delivered Rule Lives in `rules/`](adr/43-only-a-delivered-rule-lives-in-rules.md) | 2026-09-07 | The folder announces a delivery mechanism, so the seven plugin-internal contracts moved to `resources/`. |

| [66.
