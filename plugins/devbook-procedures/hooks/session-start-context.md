This repository may carry its own procedure skills under .agents/skills/ — start, show, capture, debug — each reachable by name through a wrapper per host. Invoke the skill instead of guessing a command, a URL, or a layout: start leaves the application running and reports its entry points; show starts it, opens what the current branch changes, walks it, and takes evidence; capture takes evidence a reviewer can open, one file per checkpoint and per failure, the form named honestly; debug finds the cause of an observed issue from logs, traces, and breakpoints without handing the person a debugger, and leaves nothing behind in the change. The goal in each wrapper is fixed; the procedure is the repository's — edit .agents/skills/<name>.md, never the wrapper. A skill that is absent here was not adopted: do without it and say so, never invent the procedure.
