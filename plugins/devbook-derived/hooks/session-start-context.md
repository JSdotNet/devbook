This repository may keep derived devbook indexes under _meta/ folders, written by devbook-derived's generator at .devbook/_tools/devbook-meta/build.mjs. Files under any _meta/ folder are generated tool input: never read one as a source of fact, never hand-edit one, and never regenerate or commit one in a session - the scheduled refresh owns that, and a session that regenerates beside a chapter edit is what makes the JSON conflict on merge. Fix what `build.mjs --check` reports in the source Markdown. An annotation fence is written only through .devbook/_tools/devbook-meta/annotations.mjs, never by hand.
